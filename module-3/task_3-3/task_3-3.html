1. What is the difference between invoking and creating a function?

    2. Creating a function defines its structure and behavior, while invoking a function executes it. When you create a function, you are defining what it should do, but it doesn't execute until you invoke it.

  2. Explain the syntax regarding semicolons and code blocks.

    3. Semicolons are used to terminate statements in JavaScript, although they are sometimes optional. Code blocks are defined by curly braces {} and are used to group statements together.

  3. What happens when we try to store values from a function when it doesn't return any?

    4. When we try to store values from a function that doesn't return any, the variable will be assigned the value `undefined`.

  4. How do we separate parameters from each other when creating a function?

    5. Parameters are separated by commas when creating a function.

  5. Explain how parameter names are related during the invocation and creation of a function.

    6. Parameter names in the function definition are used to reference the values passed during the function invocation. The order of the arguments in the invocation should match the order of the parameters in the function definition.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    7. When a function call is missing a parameter, the corresponding parameter in the function definition will be assigned the value `undefined`.

  7. Explain what happens when we use recursive functions.

    8. When we use recursive functions, the function calls itself. This allows us to solve problems that can be broken down into smaller, similar subproblems. However, it's important to include a base case to prevent infinite recursion.
