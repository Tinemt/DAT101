1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Use constants for values that never change, and variables for values that may change.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentheses can change the order of operations in an expression, ensuring that the operations inside the parentheses are performed first.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. We can use the `toFixed()` method to limit the number of decimals in a floating-point number.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We can use a small tolerance value to check if the absolute difference between the two values is less than this tolerance.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators return a boolean value (true or false). We can check their result directly in conditional statements or by assigning them to variables and then checking those variables.

  6. How does the Math.random() function work, and what can it be used for?

    7. The Math.random() function generates a random floating-point number between 0 (inclusive) and 1 (exclusive). It can be used for generating random numbers within a specific range or for creating randomized behavior in applications.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. The modulus operator (%) returns the remainder of a division operation. It is useful for determining if a number is even or odd, or for wrapping around values in cyclic operations.
